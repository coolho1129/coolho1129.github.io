# coolho1129.github.io

Personal academic website of Chanho Kim (M.S./Ph.D. student, UNIST AIGS).
Built with Jekyll and the Minimal Mistakes theme, served by GitHub Pages.

- Page content: `_pages/about.md` (served at `/`)
- Site settings, sidebar links, link-preview image: `_config.yml`
- Top menu: `_data/navigation.yml`
- Custom styles: `assets/css/main.scss`
